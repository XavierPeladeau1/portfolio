Prévision des fluctuations des taux d'intérêt

🏆 Compétition étudiante - Gagnant - Défi IA 2025 (CDPQ)
▼

Prévision multi-horizon des rendements des bons du Trésor américain à 10 ans utilisant l'apprentissage profond et des modèles statistiques. Travail initial réalisé dans le cadre de la compétition Défi IA 2025 organisée par la Caisse de Dépôt et Placement du Québec (CDPQ), que mon équipe et moi avons remportée en janvier 2025.

PyTorch Darts TFT N-HiTS LSTM XGBoost FRED API
  • Prévision multi-étapes (1 à 36 mois à l'avance)
  • Sorties probabilistes avec intervalles d'incertitude
  • Validation par fenêtre glissante avec comparaisons de référence
  • Données publiques via l'API FRED

Caractéristiques principales

  • Prévision multi-étapes : Prédictions de 1 à 36 mois à l'avance
  • Sorties probabilistes : Prévisions par quantiles avec intervalles d'incertitude
  • Évaluation rigoureuse : Validation par fenêtre glissante, divisions chronologiques, comparaisons de référence
  • Données publiques : Intégration de l'API FRED pour la reproductibilité

Pile technologique

  • Modèles : PyTorch (LSTM, Transformers)
  • Framework : Bibliothèque de séries temporelles Darts
  • Données : API Federal Reserve Economic Data (FRED)

Résultats

Comparaison des performances sur différents horizons de prévision (plus faible est meilleur) :

Modèle Catégorie 1 mois MAPE 3 mois MAPE 12 mois MAPE 36 mois MAPE
Naïf Extrapolation 7.7% 18.2% 53.6% 84.4%
AR(12) Extrapolation 7.6% 16.9% 52.7% 65.0%
VAR Régression multivariée 17.3% 38.7% 90.5% 57.2%
Lasso Régression univariée 7.4% 16.2% 43.2% 53.5%
N-HiTS Non-paramétrique 7.2% 16.4% 44.8% 54.9%
TFT Non-paramétrique 7.3% 16.1% 42.6% 53.0%
Principales conclusions :
  • Meilleur court terme (1 mois) : N-HiTS atteint 7.2% MAPE, surpassant tous les modèles y compris la référence naïve
  • Meilleur long terme (36 mois) : TFT excelle sur les horizons étendus avec 53.0% MAPE vs. 84.4% pour le naïf
  • ML classique : La régression Lasso est compétitive avec l'apprentissage profond sur les horizons courts/moyens, offrant une meilleure interprétabilité

Sources de données

  • Primaires : API FRED (rendements du Trésor, chômage, IPC, taux des fonds fédéraux, S&P 500, PIB, emploi, anticipations d'inflation)
  • Sentiment : SF Fed Daily News Sentiment Index (ensemble de données public)

Toutes les sources de données sont accessibles publiquement pour la reproductibilité.

Prévision de la consommation d'électricité

Projet de cours - Apprentissage automatique II
▼

Prévision de séries temporelles de la consommation d'électricité dans les régions du Québec utilisant des modèles statistiques classiques et des approches d'apprentissage profond. Développé dans le cadre du cours MATH60630 (Apprentissage automatique II) à HEC Montréal.

SARIMAX TCN Python Geopandas Meteostat Google Maps API

Aperçu

Ce projet analyse et prévoit la consommation d'électricité pour différentes Municipalités Régionales de Comté (MRC) et secteurs au Québec en utilisant des données historiques d'Hydro-Québec. L'analyse intègre des données météorologiques (température) et des informations géographiques pour améliorer la précision des prévisions dans divers segments de consommateurs (résidentiel, commercial, industriel, agricole).

Pile technologique

  • Modèles statistiques : ARIMA/SARIMAX
  • Apprentissage profond : Réseaux convolutifs temporels (TCN)
  • Traitement des données : Python, Pandas, NumPy
  • Géospatial : Google Maps API, Geopandas
  • Données météorologiques : API Meteostat

Caractéristiques

Traitement des données
  • Agrégation des données historiques de consommation d'électricité par MRC et secteur
  • Intégration des données de température utilisant des coordonnées géographiques
  • Interpolation des valeurs manquantes basée sur la proximité spatiale utilisant l'API Google Maps
  • Ingénierie de caractéristiques avec variables saisonnières et météorologiques
Approches de modélisation
  • SARIMAX : Capture les tendances et motifs saisonniers, intègre des variables exogènes (température, type de secteur), fournit des coefficients interprétables
  • Réseaux convolutifs temporels (TCN) : Traitement parallèle des séries temporelles, modélisation des dépendances à long terme, calcul efficace pour les longues séquences

Sources de données

  • Hydro-Québec : Consommation d'électricité historique par MRC et secteur
  • Meteostat : Données de température historiques pour les régions du Québec
  • API Google Maps : Coordonnées géographiques pour l'analyse spatiale des MRC

Principales conclusions

Le projet compare les performances de prévision entre différentes architectures de modèles :

  • SARIMAX excelle dans la capture de motifs saisonniers clairs avec des paramètres interprétables
  • TCN démontre de fortes performances dans la modélisation de dépendances temporelles complexes

La sélection du modèle dépend de la combinaison spécifique MRC-secteur, de la disponibilité des données et des exigences d'horizon de prévision.

Plateforme d'orchestration de workflows Prefect

Projet professionnel - Québecor
▼

Plateforme d'orchestration de workflows Prefect prête pour la production, auto-hébergée, déployée sur Google Cloud Platform avec provisionnement Infrastructure-as-Code et CI/CD automatisé.

GCP Terraform Docker Prefect Cloud Run Cloud Build PostgreSQL Redis
  • Provisionnement complet de l'infrastructure avec Terraform
  • Réseau VPC avec adressage IP privé et règles de pare-feu
  • Pipeline CI/CD GitOps avec builds Docker automatisés
  • Configuration Docker Compose multi-services (PostgreSQL, Redis, serveur/worker Prefect)
  • Exécution serverless de workflows sur Cloud Run

Aperçu

Ce projet démontre la conception et l'implémentation d'une plateforme évolutive d'orchestration de workflows de données utilisant Prefect, déployée sur Google Cloud Platform avec provisionnement d'infrastructure entièrement automatisé via Terraform.

Compétences techniques et implémentation

  • Infrastructure as Code Terraform : Infrastructure GCP complète provisionnée avec des fichiers de configuration modulaires pour les ressources de calcul, réseau, sécurité et CI/CD
  • Architecture Cloud GCP : Réseau VPC avec adressage IP privé, connecteur Serverless VPC Access pour l'intégration Cloud Run, Service Networking pour Cloud Build, et règles de pare-feu zero-trust
  • Orchestration de workflows Prefect : Pipelines de données basés sur Python avec dépendances de tâches, déploiements planifiés, et exécution distribuée sur infrastructure serverless Cloud Run
  • Pipeline CI/CD GitOps : Builds d'images Docker automatisés et synchronisation de déploiement de workflows via Cloud Build, déclenchés à chaque commit sur la branche principale
  • Docker et orchestration de conteneurs : Gestion multi-services avec Docker Compose (PostgreSQL, Redis, serveur/worker Prefect), images personnalisées avec dépendances de workflows, et exécution serverless
  • Implémentation de sécurité : Isolation réseau sans accès public à la couche d'orchestration, comptes de service IAM avec permissions minimales, gestion des secrets, et SSH via Identity-Aware Proxy

Architecture des composants

Serveur Prefect (basé sur VM)

  • Serveur : API REST et interface Web pour la gestion des workflows
  • Base de données : PostgreSQL pour les métadonnées et l'historique d'exécution des workflows
  • Worker : Interroge les workflows planifiés et provisionne les jobs Cloud Run
  • Redis : Couche de cache pour améliorer les performances

Exécution de workflows (Cloud Run)

  • Exécution de conteneurs serverless avec auto-scaling
  • Image Docker personnalisée avec code et dépendances des workflows
  • Connectivité VPC sécurisée au serveur Prefect
  • Environnement d'exécution isolé par exécution de workflow

Infrastructure (gérée par Terraform)

  • VM Compute Engine avec configuration Docker automatisée
  • Réseau VPC avec isolation de sous-réseaux
  • Règles de pare-feu pour la sécurité
  • Comptes de service avec IAM à privilèges minimaux
  • Cloud Build pour l'automatisation CI/CD

Application de visualisation de géolocalisation

Projet de stage
▼

Application Web interactive pour visualiser les données de localisation d'appareils mobiles avec animations en temps réel et informations géographiques. Développée dans le cadre d'un stage chez Vidéotron à l'été 2019.

JavaScript Leaflet.js Maps API Animations CSS
  • Visualisation cartographique interactive
  • Analyse de données de géolocalisation
  • Animations et styles personnalisés

Aperçu

Construite avec JavaScript vanilla, cette application fournit une interface intuitive pour explorer les modèles de mouvement d'appareils mobiles dans les régions géographiques. La visualisation combine des cartes interactives avec des animations personnalisées pour présenter les données de localisation dans un format accessible.

Pile technologique

  • JavaScript vanilla
  • Leaflet.js / Maps API
  • Animations CSS personnalisées

Caractéristiques

  • Visualisation interactive basée sur une carte des données de localisation
  • Analyse et traitement des données en temps réel
  • Animations personnalisées pour les transitions géographiques
  • Design responsive pour diverses tailles d'écran
